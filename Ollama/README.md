Prerequisites(Windows):
1. Install python3.
2. Install required libraries via pip install ollama pydantic python-docx PyPDF2 openpyxl python-pptx colorama.
3. Install and Setup ollama.
4. Run Ollama.exe and then run the Model_Download.py script to download models.

Usage:
1. Run Ollama.exe.
2. Run Ollama_chat.py to finally run the model and chat/work.

Tips:
1. Enter "quit chat" as your promt when you want to exit.
2. Enter "__noatt__" at the start(or anywhere) of your prompt if you donot want to provide file attachments. (Or you can just click cancel in the popup).
